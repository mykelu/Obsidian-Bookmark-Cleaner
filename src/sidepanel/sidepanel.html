      Help & Support

      This tool helps you review bookmarks, identify broken or duplicate links, and capture useful content into your notes when needed.

      Use the extension in three simple steps: check the Dashboard, run a scan, then review results before capturing, archiving, or updating bookmarks.

      Welcome

      Welcome to the bookmark review and capture workspace.

      This extension is designed to keep your bookmarks organized while preserving useful information for later reference.

      Getting Started

      Open Dashboard first. This gives you a quick view of system status, worker readiness, and recent activity.

      Use Scan to analyze bookmarks and detect issues. Use Review to inspect results before taking action.

      Dashboard

      The Dashboard is the main working area. It shows current system status, summary counts, and quick actions.

      Service Worker Status shows whether the background worker is responding right now. This status is checked automatically when the Dashboard opens.

      If the worker is not responding, use Refresh Worker Status and wait a moment while the worker starts up.

      Scanning Bookmarks

      Use Scan when you want to check the health of your bookmarks.

      The extension may classify bookmarks as healthy, redirected, duplicate, soft-broken, or hard-broken.

      Soft-broken links may still become available later, so they should usually be reviewed or rechecked instead of deleted immediately.

      Reviewing Results

      Use Review to inspect bookmarks before making changes.

      Redirected links can often be updated to a newer destination, duplicates can be cleaned up, and broken links can be reviewed before archival or removal.

      For safety, bookmarks should not be permanently deleted without confirmation.

      Connecting Obsidian

      If you want to send content to Obsidian, open Settings and expand Obsidian Integration.

      Enter your Obsidian Local REST API URL, API key, destination folder, and filename preferences.

      Use Test Connection before capturing notes to confirm that the connection is working correctly.

      Settings

      Settings contains optional controls and advanced configuration.

      Use Settings to manage integrations, scan preferences, interface visibility, and advanced options.

      Some controls are hidden by default to keep the interface clean. Turn them on only when you need them.

      Diagnostics

      Diagnostics are optional and mainly useful for troubleshooting.

      You can show diagnostics when you need to review worker status checks, recent runtime messages, or error details.

      If everything is working normally, you usually do not need to keep diagnostics visible.

      Troubleshooting

      If the Dashboard says the worker is not responding, refresh worker status and wait a moment.

      If Obsidian does not connect, verify the API URL, API key, and certificate trust settings.

      If extraction does not work on a page, the site may require login, may block access, or may not allow clean extraction.

      If a bookmark appears broken, try rechecking it before deciding to archive or remove it.

      Privacy and Safety

      This extension is designed to support review-first workflows.

      Bookmarks should not be permanently deleted without confirmation, and temporary errors do not always mean a bookmark is invalid.

      Captured content is only sent to destinations you configure.

      Privacy and Data Handling

      Local Processing: All bookmark scanning, duplicate detection, and health checks are performed locally within your browser.

      No External Analytics: This extension does not use external analytics tracking or third-party data collection services.

      Data Destinations: Data is only sent to the Obsidian Local REST API if you have configured and enabled the Obsidian Integration.

      Minimal Permissions: The extension only requests the permissions necessary to manage bookmarks, extract content for your notes, and connect to your local Obsidian instance.
